    导出

    批量导入

    拖入 .json 文件，或点这里选文件
    支持 [ {id,name,...,nodes:[]} ] 或单个对象
    还没选文件

    说明

    写操作要带口令（X-Admin-Token）。没有口令时这里只能看，点保存会提示输入。
    线上口令在 Render 环境变量 ADMIN_TOKEN；本机没配时只放行 127.0.0.1。
    免费层 SQLite 重启会清空，录完数据一定先导出再 push。

    管理口令

    没有口令也能浏览；写操作会被拒绝（401）。
